# Adam Alston — Portfolio landing page

A responsive, single-page portfolio inspired by the supplied reference photos: black starfield background, warm gold typography, and centered social/contact icons.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a browser. No build tools are required.

## Customize before publishing
- Change `Adam Alston` and `Software Engineer` in `index.html`.
- Replace the GitHub and LinkedIn URLs with your profiles.
- Add your resume as `resume.pdf` in this folder.
- Replace `hello@example.com` with your email address.
- Edit the tagline and availability note if needed.

The starfield and pointer sparkles are generated locally with Canvas. Google Fonts is used for Inter; a system font fallback is included.
